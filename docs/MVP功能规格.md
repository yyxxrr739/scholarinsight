# ScholarSight MVP 功能规格说明

## 📋 MVP 功能范围确认

基于需求讨论，MVP阶段专注于核心功能，确保网站能够快速上线并满足基本使用需求。

## 🎯 目标用户
- **主要用户**：研究人员、学生、政策制定者、科技战略家
- **使用场景**：学习新领域、了解最新进展、了解学术脉络、分析研究机构模式、评估创新生态
- **访问方式**：无需注册，直接浏览

## ✅ MVP 必须功能

### 1. 网站基础框架
- **响应式设计**：适配桌面、平板、手机
- **现代化UI**：学术专业风格，简洁清晰
- **基础导航**：首页、报告、学者档案等主要页面
- **SEO优化**：搜索引擎友好的页面结构

### 2. HTML报告展示功能
- **报告列表页**：展示所有可用报告，支持分类筛选和搜索
- **报告详情页**：完整展示HTML格式报告，包含元信息和操作功能
- **报告分类**：按类型分类（学者分析、机构分析、企业分析等）
- **报告搜索**：支持标题、描述、标签、主体名称等关键词搜索
- **报告元信息**：标题、日期、摘要、作者、分类、标签等
- **主体类型**：支持学者、研究机构、企业等多种分析对象

### 3. 学者档案展示（基于报告内容）
- **学者列表页**：展示学者基本信息，数据来源于HTML报告
- **学者详情页**：展示学者的详细分析报告
- **静态数据**：MVP阶段使用预设的学者数据
- **基础搜索**：按姓名、机构、领域搜索学者

### 4. 基础页面结构
- **首页**：网站介绍、合作网络可视化、最新报告展示
- **报告页面**：报告列表、报告详情
- **学者页面**：学者列表、学者详情
- **网络页面**：学者合作网络可视化
- **关于页面**：网站介绍、联系方式

## 🚫 MVP 阶段不需要的功能

### 用户系统
- 用户注册登录
- 个人中心
- 收藏功能
- 用户贡献内容

### 高级功能
- 机构动态跟踪
- 数据统计分析
- 高级搜索筛选
- 外部API集成
- 批注功能

### 内容管理
- 后台管理系统
- 报告版本管理
- 内容审核机制
- 用户反馈系统

## 📁 数据管理方案

### HTML报告管理
- **存储方式**：静态HTML文件存储在 `public/reports/` 目录
- **添加方式**：手动上传HTML文件到指定目录
- **元数据管理**：通过JSON配置文件管理报告信息（标题、日期、分类、标签等）
- **更新方式**：通过Git提交更新报告和元数据
- **支持类型**：学者分析、机构分析、企业分析等多种报告类型

### 报告元数据管理
- **数据格式**：JSON配置文件
- **存储位置**：`data/reports.json`
- **字段包含**：标题、描述、作者、日期、分类、标签、主体信息等
- **更新方式**：手动编辑JSON文件
- **主体信息**：支持学者、研究机构、企业等多种分析对象

## 🛠️ 技术实现方案

### 前端技术栈
- **框架**：Next.js 14 (React 18)
- **样式**：Tailwind CSS
- **语言**：TypeScript
- **部署**：支持静态导出

### 数据管理
- **报告数据**：静态HTML文件 + JSON配置文件
- **元数据管理**：JSON配置文件存储报告元信息
- **搜索功能**：客户端搜索（无需后端）
- **分类管理**：配置文件管理
- **可视化**：D3.js实现合作网络图

### 部署方案
- **开发环境**：本地开发服务器
- **生产环境**：Vercel部署

## 📊 页面结构设计

### 首页 (`/`)
- 网站介绍和特色
- 学者合作网络可视化
- 最新报告展示（2-3个）
- 快速搜索入口

### 报告页面 (`/reports`)
- 报告列表（网格显示）
- 分类筛选（学者分析、机构分析等）
- 类型筛选（学者、机构、企业）
- 搜索框
- 排序选项（时间、标题、分类）

### 报告详情页 (`/reports/[filename]`)
- 完整HTML报告展示
- 报告元信息
- 返回列表按钮
- 分享和下载功能

### 学者页面 (`/scholars`)
- 学者列表（网格显示）
- 搜索和筛选
- 学者卡片展示
- 排序选项

### 学者详情页 (`/scholars/[id]`)
- 学者详细信息
- 研究领域标签
- 报告内容展示
- 批注功能

### 网络页面 (`/network`)
- 学者合作网络可视化
- 交互式网络图
- 学者信息展示
- 搜索和筛选功能
